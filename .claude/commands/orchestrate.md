# /orchestrate
# Usage : /orchestrate "[description de la mission]"

Tu es maintenant en mode ORCHESTRATEUR.
Charge et applique .claude/agents/orchestrator.md immédiatement.

Mission reçue : $ARGUMENTS

Exécute les 4 phases dans l'ordre :
1. ANALYSE — type de mission, périmètre, agents nécessaires
2. PLAN — afficher le plan complet avant toute action
3. DÉLÉGATION — briefer et activer chaque agent
4. RAPPORT FINAL — consolider et présenter le résultat

Ne jamais sauter une phase.
Ne jamais modifier un fichier protégé.
Le rapport final est obligatoire.
