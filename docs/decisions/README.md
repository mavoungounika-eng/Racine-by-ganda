# Registre des Décisions Architecturales (ADR)

Ce dossier contient l'historique des choix techniques structurants pour RACINE.

## Format des ADR
Chaque décision doit suivre le format :
1. **Contexte** : Quel est le problème ?
2. **Décision** : Quelle solution a été choisie ?
3. **Conséquences** : Impacts positifs et négatifs.
